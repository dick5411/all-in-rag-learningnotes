## 1.1 什么是 RAG？
RAG，检索增强生成，全称 Retrieval-Augmented Generation。

简单理解：

传统大模型：
用户提问 → 大模型直接回答。

RAG：
用户提问 → 检索知识库 → 获取相关资料 → 大模型阅读资料结合用户问题 → 生成答案。

它的核心思想是：
**在大模型生成答案之前，先从外部知识库中检索与用户问题相关的信息，再将检索结果作为上下文提供给大模型，让大模型基于这些信息生成答案。**
